# Motion-led look

A working method for the look of a deck shown to a room, where holding attention is the point: a kick-off, a launch, a workshop, a keynote. It finds a look that moves and that the owner likes, before any content is placed.

These rules come from two decks made this way. In both, the owner rejected the first looks as correct but boring, and liked the result only after the steps below. Each rule fixes one cause of a thrown-away round.

This file extends stage 4 (Look round) of `slides.md`. The playbook's phases, gates, review pages, versions and wording rules still apply. This file says what is different when motion carries the look.

- The owner steers the direction: does it fit the room, the brand and the message.
- The agent owns the creative choices: the ideas, the motion, the assets. Bring the owner finished options, not questions about taste.
- "The theme is right" is not "the look is right". The brand sets colours, type and logos. The ideas inside the slides are the agent's work, and they are what the owner judges.

## The order

| Step | What the owner sees | The owner's review point |
| --- | --- | --- |
| 1. Brand kit | Nothing new. The kit is in hand (`slides.md` 2.1) | None |
| 2. Motion concepts | Eight to ten moving concepts on the real cover slide | **Pick one direction** |
| 3. One idea per slide | Two or three moving ideas for each slide, inside the direction | **Pick one idea per slide** |
| 4. Scale and placement | The picked slides at full screen, before beside after | **Approve the scale** |
| 5. Content | The words and facts in place | Gate 3 of `slides.md` |
| 6. Slide order | The running order | Inside gate 3 |

A sibling deck in a look the owner already approved (for example a workshop after its kick-off) starts at step 2 with three or four directions instead of ten, shown on four sample slides (rule 3).

Content and slide order wait until the look is approved. A deck built content first, with the theme painted on, comes back as generic.

## 1. Motion concepts

1. **Make eight to ten concepts, each one metaphor.**
   - Draw each concept from the message: building blocks for a build event, a picture that sharpens for clearer instructions, a sentence that types itself for a talk about conversation.
   - Write the metaphor in one line beside each concept.
   - Make each concept clearly different in idea, not a colour or layout variant of another.

   Why: a set of static themes that only follow the brand guide is read as "correct, but where is the creativity", and the whole set is thrown away.
2. **Build every concept as a live, looping slide in the brand.**
   - Use the real cover slide: real title, real logos, real fonts.
   - Keep body text solid and readable. The motion lives in the picture area and around the title.
   - Size everything in units of the slide, so a preview scales to any card width.

   Why: the owner judges motion by watching it, and a concept that only works at one size breaks on the review page.
3. **Show three or four directions on four sample slides when the brand look is already approved.**
   - The four slides: the title, one idea, one interaction or game, one section break.
   - Each direction gets the same four slides, so the owner compares directions, not content.

   Why: four slide types show whether a direction holds across a deck, and the same slides keep the comparison fair.
4. **When the owner asks to merge two directions, build the merge as a new direction.**
   - Keep both originals unchanged beside it.
   - Say in one line which part comes from which direction.

   Why: a merge that overwrites an original loses the version the owner may want back.

## 2. One idea per slide

1. **Give each slide its own idea inside the picked direction.**
   - Make two or three ideas per slide. The direction's picture appears once, at its best slide, not on every slide.
   - Each idea shows what the slide says: gifts for "what you get", a path for the week ahead, linked pieces for judging.

   Why: one picture repeated on every slide is read as one trick used too often, and it costs a round of new ideas.
2. **Check every idea against the generic set before the owner sees it.**
   - The generic set: card grids, rows of rounded boxes, tiles of icon plus title plus text, plain bullet lists, three-column layouts, stock gradient blobs, emoji and clip art.
   - When a slide falls into the set, find the one idea the slide carries and draw that instead.
   - Each slide holds one idea and one place for the eye.

   Why: a deck whose inside elements come from the generic set is rejected even when the theme is right.
3. **Check that each picture says what the content says.**
   - Name what the picture shows in plain words. When the name could mislead the audience, change the picture or the label.

   Why: a picture that suggests the wrong thing is sent back, whatever its quality.

## 3. Motion on the review page

1. **Show every motion choice moving.**
   - Use the live slide in the card, or a short looping clip of the real slide.
   - Show each language side by side when the deck has more than one, with the right-to-left version mirrored.
   - A clip can be recorded from a headless browser, frame by frame, and joined into a short loop.

   Why: ideas shown as stills are judged as static, and the owner asks where the motion is.
2. **Ask how much the slides move, as its own card.**
   - Options: loop the whole time, play once then hold still, or move only on a click.
   - Recommend play once then hold for a talk, so the motion does not compete with the speaker.

   Why: motion that never stops pulls the eye from the presenter, and the owner decides the balance by seeing both.

## 4. Scale and placement

1. **Size for the room, then check at full screen.**
   - Check every slide at the show resolution: one headline, text sized for the back row, nothing touching the edges.
   - Put logos at the same height and level with each other, in the corners the brand sets.
   - When the owner says the slide is zoomed in or out, change the scale of text and pictures together, so lines break where they did.

   Why: a slide sized on a laptop looks crowded or lost on a screen, and a scale round is spent fixing it.
2. **Check every text style against the brand guide.**
   - Include the small styles: labels, quotes, comments, numbers.
   - Use only faces the guide names. Use a highlight colour from the palette.

   Why: an accent face the guide does not name is the first thing a brand-aware owner sends back.

## 5. Assets and tools

1. **Agree the spend before the concepts.**
   - At the brief, ask whether generated pictures, animation files or 3D pieces are welcome, and the spend limit (`slides.md` 1.5).
   - Inside the limit, use them where they carry an idea better than code can. Keep every word live text.

   Why: without a limit the agent skips generated assets to save money, and the owner's ask for them goes untried.
2. **Build motion as code inside the slides first.**
   - Use CSS animation or a motion library in the slide page, so the deck runs offline in the room.
   - Use the motion-designer skill to plan the timing, easing and staging.
   - Use a video tool such as HyperFrames only when a video file is the output.

   Why: a deck that needs a network or a video player to move fails in a room with bad Wi-Fi.
3. **Give every motion a rest pose for exports.**
   - A PDF or picture export does not run animation time. Set a still state that shows each idea at rest.
   - Check the export pages, not only the live deck.

   Why: an export made mid-animation shows blank or half-built pictures.

## Research to start from

Read these before the concepts, and cite them in the "Based on" line of the round:

- Mayer's signaling and coherence principles from multimedia learning research.
- One idea per slide, from presentation design practice.
- Explorable explanations: ideas the audience watches change, not read about.
- Purposeful motion in interface design research: motion that shows a change, a link or a result.

## Traps

| Trap | What it cost | The rule that prevents it |
| --- | --- | --- |
| Static themes that only follow the brand guide | A whole round of themes thrown away | 1.1 |
| One picture used on every slide | A round of new ideas per slide | 2.1 |
| Motion ideas shown as stills | A round redone as moving clips | 3.1 |
| A deck built content first, with the theme painted on | A full deck rejected as generic | The order |
| Card grids for the inside elements | Named as generic in the rejection | 2.2 |
| An accent face the guide does not name | A slide sent back | 4.2 |
| Text and pictures sized on a laptop | A scale round | 4.1 |
| Generated assets skipped with no spend agreed | The owner's ask left untried | 5.1 |
